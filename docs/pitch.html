Agenda Solidária

API REST para a agenda de atendimentos voluntários da SSVP Quixadá.

Felipe Freires da Costa · 2023010627

O problema

  • Horário duplicado no caderno
  • Vaga ociosa que ninguém vê
  • Falta sem registro
  • Sem número para prestar contas

A modelagem

UML: casos de uso, classes, sequência e estados.

Clean Architecture + SOLID.

GoF: Strategy, State, Observer, Adapter, Factory Method.

O MVP

API em Java 17 e Spring Boot. 20 endpoints. CPF mascarado (LGPD).

Tela da associação em http://localhost:8080/

Relatório: pessoas atendidas, especialidade, taxa de comparecimento.

O benefício

Mais famílias atendidas com as mesmas horas voluntárias.

Vagas distribuídas com limite por pessoa.

Dados para editais, parceiros e doadores.
